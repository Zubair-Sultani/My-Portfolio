# Premium Portfolio Stack

This workspace contains a Next.js 15 + React 19 frontend and an Express + Node.js backend for a premium portfolio website.

## Structure

- `frontend/`: Next.js 15 app
- `backend/`: Express API and admin backend

## Setup

```bash
npm install
npm run dev
```

## Features

- Modern portfolio UI with glassmorphism, animations, dark/light mode
- NextAuth authentication
- MongoDB models and API routes
- SEO, performance, accessibility
